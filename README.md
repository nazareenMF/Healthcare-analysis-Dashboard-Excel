# Healthcare Data Analysis Using Excel

## Project Overview
This project focuses on analyzing healthcare data using Microsoft Excel. The objective is to clean, transform, and analyze healthcare information to identify patterns and insights related to patient health conditions, medical examinations, hospitalisation, and medical charges.

## Dataset Description
The workbook contains the following sheets:
- **Customer Names:** Customer identification and name details.
- **Medical Examinations:** BMI, HbA1C, heart issues, cancer history, smoking status, and major surgeries.
- **Hospitalisation Details:** Patient age, date of birth, hospital tier, city tier, and medical charges.
- **Health Care:** Consolidated dataset combining relevant healthcare information.
- **Pivot Table and Charts:** Summary analysis and visualizations.
- **Healthcare Dashboard:** Dashboard workspace.

## Data Cleaning & Preparation
- Handled missing values and inconsistent data.
- Standardized categorical values.
- Split full names into separate columns using Text to Columns.
- Converted numerical fields into appropriate data types.
- Created calculated columns for age and weight status.
- Formatted date of birth into a consistent date format.
- Combined multiple datasets using Customer ID and VLOOKUP.

## Excel Tools & Techniques
- VLOOKUP

- Text to Columns

- Data Formatting

- Pivot Charts
- Data Visualization

## Key Analysis
- Cancer history among smokers and non-smokers.
- Major surgeries and average HbA1C based on transplant status.
- Medical charges by weight status and diabetes status.
- Hospital tier distribution across different states.
- Healthcare patterns based on patient age and medical conditions.
